# Minimalist Ad Studio

Internal prototype for [Minimalist](https://beminimalist.co): generate ad creatives from a product URL, and score any ad against brand + compliance rules before spend.

**PM assignment — see [docs/decision-doc.md](docs/decision-doc.md) for the one-page decision doc.**

## What's here

- `app/` — the working tool (Part A: generator, Part B: scorer)
- `docs/` — decision log, decision doc, failure modes
- `evidence/` — brand evidence the rules are derived from (product page notes, real ad examples)
